# Docker: обязательные ограничения пользователя

- Не создавать больше **трёх Docker-контейнеров суммарно**, включая уже существующие, остановленные и временные контейнеры. Перед созданием проверять `docker ps -a`; учитывать все контейнеры текущего Docker daemon.
- Переиспользовать существующие контейнеры. Не создавать параллельные тестовые Compose-проекты. Если свободного места в лимите нет, использовать нативный запуск или проверки без контейнеров; чужие контейнеры не удалять.
- Хранить один актуальный образ приложения `researchmind:local`. Не накапливать безымянные старые сборки и дополнительные тестовые теги. После замены образа удалять именно старые сборки этого проекта, проверив, что они не используются.
- Образы зависимостей загружать только для необходимого запуска. Не запускать глобальную очистку чужих Docker-ресурсов. Данные, модели и тома не удалять без отдельного указания.
- Compose содержит не больше трёх сервисов: приложение (подготовка, API и UI), Qdrant и Ollama. Перед запуском учитывать контейнеры, уже существующие вне проекта.
